# PPTX比較対応 実装計画（登録版）

最終更新: 2026-02-14

- 運用前提: `index.html` のダブルクリック起動（ブラウザ単体）を維持
- 開発方針: 各タスクを優先度順に実施し、可能な範囲でTDDを先行

## フェーズ0: 事前準備
- `docs/pptx_gap_implementation_plan.md` を進捗の真実情報源として運用
- 各タスクに「受け入れ条件」を明記し、実装前に確認

## フェーズ1（P0）: 文字編集体験の完成
### 1-1. テキスト体裁（段落系）拡張
- 対象機能: 箇条書き、番号付き、インデント、行間、字間
- 期待効果: PPTXライクな本文編集
- 受け入れ条件:
  - テキストプロパティ変更が表示と内部状態に即時反映される
  - 改行を含む複数行で崩れない

### 1-2. 文字プロパティ一貫性の固定
- 対象機能: フォント/サイズ/太字/斜体/文字揃えの状態反映
- 受け入れ条件:
  - 選択時のみ関連UIが有効になり、非テキスト要素で無効値が混在しない

## フェーズ2（P0）: 基本編集操作の標準化
### 2-1. ショートカット実装
- 対象機能: `Ctrl/Cmd + C/V/X`, `Delete`, `Undo/Redo`, `Esc`
- 受け入れ条件:
  - 既存の履歴・選択状態と競合しない

### 2-2. 選択状態遷移の堅牢化
- 対象機能: クリック外し、キャンバス外クリック、プロパティ操作時、テキスト編集時
- 受け入れ条件:
  - 意図しない解除や操作取りこぼしが起きない

## フェーズ3（P1）: 多選択と整列系
### 3-1. 多選択
- 対象機能: shift/click、ドラッグ枠選択
- 受け入れ条件:
  - 複数選択時のドラッグ/削除/複製時の状態が安定

### 3-2. 整列・配置
- 対象機能: 左/中央/右/上/下揃え、等間隔・均等幅高揃え
- 受け入れ条件:
  - 選択オブジェクト群で再現性のある配置結果が得られる

## フェーズ4（P1）: 図形とレイアウト骨組み
### 4-1. 図形拡張
- 対象機能: 線、矢印、角丸矩形、菱形など
- 受け入れ条件:
  - 既存図形と同様に追加/移動/リサイズ/重ね順が使える

### 4-2. スライドテンプレート/マスター系
- 対象機能: レイアウト雛形（タイトル+本文等）、デフォルト余白・配色
- 受け入れ条件:
  - 新規スライド作成時に初期体裁が再現可能

## フェーズ5（P2）: 配置補助の実用化
### 5-1. グリッド・ガイド強化
- 対象機能: グリッド表示、スナップの整列拡張
- 受け入れ条件:
 - ON/OFFの切り替えが明確で、既存スナップ挙動を壊さない

### 5-2. 画像編集補助
- 対象機能: 画像比率ロック、透明度、簡易トリム
- 受け入れ条件:
 - 画像崩れなく拡大縮小・配置可能

## フェーズ6（P2〜P3）: 出力・表示品質
### 6-1. 出力品質整備
- 対象機能: SVG/JSON安定運用継続 + 印刷/画像出力の品質改善
- 受け入れ条件:
 - 再読込時に寸法・位置・順序が維持される

### 6-2. 簡易スライドショー
- 対象機能: 左右キーで進退、フル表示
- 受け入れ条件:
 - 編集→再生→再編集が行える

## 各フェーズ共通ルール
- 可能な範囲でテストを先に追加（TDD）
- 既存変更より実害が大きい順に進める
- 変更点は必ず `IMPLEMENTATION_STATUS.md` に進捗追記
