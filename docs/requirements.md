# SVG PowerPoint-like Editor 要件定義（v0.1）

## 1. 目的
SVGを用いて、ブラウザ上でプレゼンテーションスライドを作成・編集・保存できるWebアプリを開発する。

## 2. 想定ユーザー
- 企業内で簡易資料を作成する担当者
- 学習者・学生
- デザイナー補助的に構成図/図版を作成したいユーザー

## 3. ゴール（成功条件）
- 1つの編集画面で、最低限のスライド編集が可能であること
- 追加・編集・移動・サイズ調整・複製・削除が行えること
- データの保存・復元ができること
- スライドと要素をJSONで管理し、再編集可能であること

## 4. 機能要件

### FR-1 スライド管理
1. スライド追加
2. スライド複製
3. スライド削除（1枚のみのときは保護）
4. スライド選択の切替
5. スライドタイトル表示

### FR-2 要素編集（最低限）
1. 要素追加: テキスト、四角形、円、画像
2. 要素選択
3. ドラッグ移動
4. 端点ドラッグによるリサイズ
5. テキストダブルクリック編集
6. 前面/背面への並び順変更
7. 要素複製
8. 要素削除

### FR-3 プロパティ編集
1. 塗りつぶし色
2. 枠線色
3. テキストサイズ
4. テキスト内容

### FR-4 データ操作
1. ローカル保存（ブラウザ）
2. 再読込時の復元
3. JSONエクスポート/インポート
4. 現在スライドのSVGエクスポート

### FR-5 補助要件
1. 画面上で現在スライドと簡易ヒントを表示
2. モバイル含むサイズ変化への対応（最小可）

## 5. 非機能要件
- 1ファイル1スライドあたりのレンダリング応答時間: 500ms以内
- 意図しないデータ消失を防ぐため定期保存を行う（localStorage）
- 操作中の状態は視覚的にわかりやすくする
- 入力バリデーションとエラーメッセージを出す（JSON読込時など）

## 6. 開発対象外（v0.1）
- シェープの高度なアライメント（グリッド吸着など）
- 共同編集、クラウド同期
- Markdown/HTML埋め込み、動画要素
- プレゼン実行モードの高度機能（スライドショーモード）

## 7. 受け入れ条件
- 主要要件を1セッションで作成・編集・保存・再読込できること
- JSON→再読込で図形/テキスト位置・サイズ・順序が崩れないこと
- 要素の追加〜削除の基本動作が破綻しないこと
