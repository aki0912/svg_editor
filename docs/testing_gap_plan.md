# テスト不足解消計画（単一計画）

最終更新: 2026-02-14

## 目的
- 既存の複数計画を廃止し、本計画に一本化する。
- 現在の実装で不足しているテスト項目を網羅的に追加し、回帰を防止する。
- `index.html` のダブルクリック起動（ブラウザ単体動作）を維持したまま品質を引き上げる。

## 開発方針
- TDDで進める。
- 1機能ごとに「失敗するテスト追加 -> 実装 -> リファクタ」の順で実施する。
- 仕様不明点は先に期待挙動をテストで明文化してから実装する。
- 既存不具合の再発防止は必ず回帰テストを先に作る。

## 現在の不足領域（要追加）
- `app.js` の主要挙動に対する自動テストが不足している。
- SVGインポート/エクスポートの座標・テキスト配置の回帰テストが不足している。
- テキスト編集の配置、ベースライン、編集確定周りのDOM統合テストが不足している。
- 多選択、整列、リサイズ、回転、スナップの統合テストが不足している。
- キーボードショートカットと選択状態遷移の回帰テストが不足している。
- スライド操作（作成、複製、削除、テンプレート、切替）の回帰テストが不足している。
- JSON/SVG入出力の往復整合テストが不足している。

## 追加するテスト項目一覧
- `T-001` SVGインポート時にテキストY座標が元ファイルと一致する。
- `T-002` SVGインポート時に`dominant-baseline`差異があっても表示位置が崩れない。
- `T-003` SVGエクスポート後の再インポートでテキスト位置がドリフトしない。
- `T-004` `20260213154623.svg`のゴールデン比較で主要テキスト群の位置差が許容範囲内。
- `T-005` 単一行テキストの編集開始時に表示位置がジャンプしない。
- `T-006` 複数行テキストの編集開始時に行頭と行間が維持される。
- `T-007` テキスト編集確定後に高さ再計算されても上端基準が維持される。
- `T-008` フォント変更時に日本語フォントでもレイアウト差分が反映される。
- `T-009` `textAnchor=start/middle/end` の描画位置とキャレット位置が整合する。
- `T-010` 箇条書き・番号付き・インデント適用時の表示と内部値が一致する。
- `T-011` Shift+クリックの多選択トグルが期待どおりに動作する。
- `T-012` マーキー選択で複数要素が安定して選択できる。
- `T-013` 複数選択移動時に全要素が同じΔで移動する。
- `T-014` 複数選択削除/複製が選択状態を壊さない。
- `T-015` 左/中央/右/上/下揃えの結果が幾何的に正しい。
- `T-016` 均等配置（横/縦）の間隔が等間隔になる。
- `T-017` 同幅/同高の整列結果が全要素で一致する。
- `T-018` リサイズ時スナップで固定辺が勝手に移動しない。
- `T-019` 左上ハンドルリサイズ時の原点安定性を保証する。
- `T-020` 線/矢印の回転時に端点計算が破綻しない。
- `T-021` 矢印先端と回転ハンドル位置が常に向きと一致する。
- `T-022` Undo/Redoで移動・リサイズ・回転・編集が正しく巻き戻る。
- `T-023` Undo後の新規操作でRedoスタックが破棄される。
- `T-024` Escapeで編集キャンセル時に未確定変更が保存されない。
- `T-025` Delete/Backspaceがテキスト編集中は文字削除、非編集中は要素削除になる。
- `T-026` Ctrl/Cmd+C/X/Vのコピー系でID重複が発生しない。
- `T-027` 新規スライド作成時にテンプレート内容が正しく生成される。
- `T-028` スライド複製時に要素の深いコピーがされる。
- `T-029` スライド削除時に`currentSlideIndex`が不正値にならない。
- `T-030` 前後/直接選択UIでスライド切替状態が常に同期される。
- `T-031` JSONエクスポート/インポートで全プロパティが保持される。
- `T-032` SVGエクスポートで主要図形とテキスト属性が保持される。
- `T-033` 画像要素のサイズ・位置が往復で維持される。
- `T-034` `localStorage`復元時に選択状態が安全に初期化される。
- `T-035` プロパティパネル操作中に選択解除が起きない。
- `T-036` キャンバス空白クリックで選択解除、オブジェクトクリックで選択維持が成立する。

## 実行フェーズ

### フェーズ1（P0）テキスト座標回帰ブロック
- 対象: `T-001` 〜 `T-010`
- 目的: 現在の主要不具合であるテキスト位置ずれを先に封じる。
- 完了条件: 取り込み済みSVGの主要テキスト座標がゴールデン比較で許容差内。

### フェーズ2（P0）操作安全性ブロック
- 対象: `T-011` 〜 `T-026`
- 目的: 編集操作で壊れやすい状態遷移を固定する。
- 完了条件: 多選択・整列・履歴・ショートカットの回帰テストが全件通過。

### フェーズ3（P1）スライド機能ブロック
- 対象: `T-027` 〜 `T-030`
- 目的: スライド運用系の回帰防止。
- 完了条件: 新規/複製/削除/切替がすべて自動テストで保証される。

### フェーズ4（P1）入出力整合ブロック
- 対象: `T-031` 〜 `T-036`
- 目的: 保存・再読込・UI状態遷移の一貫性を固定。
- 完了条件: JSON/SVG/localStorage/UI状態の往復整合を自動テストで保証。

## 実装順序ルール
- 各フェーズでテスト追加順はID順に固定する。
- 各テストの追加時に、失敗理由を1行コメントで明示する。
- 1つのテスト修正で別仕様に影響が出た場合は、同コミット内で回帰テストを追加する。
